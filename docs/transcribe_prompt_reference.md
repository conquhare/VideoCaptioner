# FasterWhisper 转写提示词参考（`--initial_prompt`）

## 原理

`--initial_prompt` 是给 Whisper 的**领域引导文本**：这段内容里出现过的词，模型会更倾向往识别结果里靠。
作用是降低长音频的幻觉/跑偏，提升专有名词（人名、品牌、术语）的识别准确率。

**写法要点**：
- 标签式关键词堆叠即可，不用成句，每类 20~50 词。
- **专有名词优先**——人名、角色名、品牌、术语最易识别错，优先列。
- 中文任务写中文词；中英夹杂把英文术语也带上（如 `LLC谐振`、`DC-DC`、`Cyberpunk`）。
- **只放确实希望出现的词**，放偏了会误导识别。
- 提示词会偏向结果，所以宁缺毋滥。

> ⚠️ 程序**没有内置默认提示词**。`FasterWhisper.Prompt` 为空时不传该参数，等于让模型纯靠猜。
> 建议按当前任务类型，从下面挑一条填进 UI 的「提示词」框（或直接改 `AppData/settings.json` 的 `FasterWhisper.Prompt`）。

## 配套转写优化建议（T400 4GB 显存）

| 项 | 建议值 | 说明 |
|----|--------|------|
| 人声分离 `FfMdxKim2` | **False（保持关闭）** | large-v2 + MDX 在 4GB 上必 OOM，已验证 |
| VAD 方法 `VadMethod` | silero_v5 | 比 ten-v5 更准更省显存，已是最优 |
| VAD 阈值 `VadThreshold` | **0.3**（默认 0.2） | 调高砍掉更多静音/噪声段，提速且减少幻觉；漏识别弱音人声再回调 |
| 缓存 `CacheEnabled` | True | 断点/重跑不重复转写；改参数后旧缓存可能不匹配，必要时清一次 |
| 分块并发 | 1（代码写死） | 4GB 无并发空间，保持单线程 |
| 模型 `Model` | large-v2 精修 / medium 快速出稿 | medium 在 4GB 更快，质量够用；精修再上 large-v2 |
| 显存吃紧时 | 可加 `--compute_type int8_float16` | 量化省显存，精度损失很小（当前仅 RTX50 系自动加 float16） |
